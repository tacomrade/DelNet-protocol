# Contributing to DelNet

Thank you for your interest in contributing to **DelNet** — an open, peer-to-peer protocol for local-first content sharing.

We welcome contributions in many forms:

- Protocol design and feedback  
- PoC code improvements  
- Cryptography implementation (Ed25519 signing, etc.)  
- Documentation, tutorials, and diagrams
